# Jcdangelo Local-kubelogin

## How do I install these formulae?

`brew install jcdangelo/local-kubelogin/<formula>`

Or `brew tap jcdangelo/local-kubelogin` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jcdangelo/local-kubelogin"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
